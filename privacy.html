Privacy Policy

Last updated: November 25, 2026

Sonar Postagem ("the app") is a private tool run by its owner on the owner's own computer to upload and schedule videos to the owner's own YouTube channels.

Data the app accesses

With the owner's authorization, the app uses the YouTube Data API to upload videos and to read basic information about the owner's channels and uploaded videos (channel ID and name, video ID, upload and privacy status).

How the data is used and stored

This data is used only to upload, schedule and confirm the owner's videos. Authorization tokens are stored only on the owner's computer. No data is sold, shared with third parties, or used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the local token files also removes the app's access.
